认知世界 PWA v2.2｜视频文件夹自动索引版

一、核心规则
- 只需要视频，不需要单独准备图片和音频。
- 每个动物/物品对应一个 0.5–3 秒短视频。
- App 自动取视频 0.2 秒附近的一帧作为静态封面。
- 点击封面后播放原视频和原音频；最长 3 秒自动停止；播放结束自动回封面。
- 不循环、不连播、不自动下一张。

二、文件命名
统一放在一个单层素材文件夹内，命名为：

组别_名称_辅助词.mp4

辅助词可以省略。

示例：
动物_大熊猫.mp4
动物_鸭子_嘎嘎.mp4
动物_小狗_汪汪.mov
交通工具_挖掘机.mp4
交通工具_救护车_呜呜.mp4
水果_苹果.mp4
家里_吸尘器_嗡嗡.mp4

解析方式：
动物_鸭子_嘎嘎.mp4
→ 组别：动物
→ 名称：鸭子
→ 辅助词：嘎嘎

三、同步逻辑
- 打开 PWA，点“同步素材”。
- 选择整个素材文件夹。
- App 会自动扫描全部视频并建立目录。
- 再次同步时做增量处理：
  1. 文件名、大小、修改时间都没变：跳过
  2. 新增或修改：重新导入并生成封面
  3. 文件夹里已经没有的文件：从 PWA 本地库删除

注意：
PWA 不能像原生 App 一样永久监听 iPad「文件」App 目录，所以新增视频后需要手动点一次“同步素材”。

四、界面
- 共读模式：给孩子看，只有封面、名称、辅助词、左右切换和点击播放。
- 家长模式：缩略图网格，可搜索，可快速选择某个素材进入共读。
- 目录自动生成：全部、最近添加、动物、交通工具、水果等。

五、部署
不需要 GitHub。
1. 解压 ZIP。
2. 登录 Netlify。
3. 用 Netlify Drop 上传整个 mango_cards_pwa_v2_2 文件夹。
4. 得到 https://xxxx.netlify.app 地址。
5. 用 iPhone/iPad Safari 打开。
6. 分享 → 添加到主屏幕。
7. 从主屏幕图标打开后，即为 PWA 使用形态。

六、离线与隐私
- PWA 程序外壳会通过 Service Worker 缓存。
- 视频和封面保存在当前设备的 IndexedDB。
- 素材不会上传到 Netlify；Netlify 只托管程序代码。
- 清除 Safari 网站数据、删除 PWA、或系统清理站点存储，可能导致本地素材丢失。
- 长期使用建议下一版增加“导出/导入素材包”。

七、素材建议
- 优先 MP4 / MOV。
- 编码优先 H.264 视频 + AAC 音频。
- 每个视频 0.8–2.5 秒最佳，最多 3 秒。
- 开头 0.2 秒尽量稳定，便于自动取封面。
- 主体占画面 50%–80%，背景简单，光线明亮。
- 不要加背景音乐，不要快速摇镜头。
